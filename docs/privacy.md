# プライバシーポリシー — MU Portal Rewrite

最終更新日: 2026年10月29日

MU Portal Rewrite(以下「本拡張」)は、武蔵野大学の学内サイトの表示を置き換える非公式の Chrome 拡張機能です。

## 取り扱う情報

本拡張は、利用者が大学サイトにログインした状態で、以下のサイトの情報(時間割・成績・出欠・お知らせ・課題・メッセージなど)を読み取り、画面の表示に使います。

- `portal.musashino-u.ac.jp`
- `musashino-u.myopenlms.net`
- `unipa.m-muscat.musashino-u.ac.jp` / `ecsn.m-muscat.musashino-u.ac.jp`

## 外部への送信

- 上記の情報を開発者や第三者のサーバーに送信することはありません。
- 大学サイトへの送信内容(課題の提出など)は、元の画面から操作した場合と同じです。
- 本拡張は情報の販売、広告、分析(アナリティクス)を行いません。
- GitHub から入れた版だけは、新しい版の有無を確かめるため `api.github.com` に問い合わせます(利用者の情報は送りません)。Chrome ウェブストア版は問い合わせません。

## 保存する情報

表示の大きさの設定と画面の状態のみを、利用者のブラウザ内(chrome.storage)に保存します。拡張機能を削除すると消去されます。
